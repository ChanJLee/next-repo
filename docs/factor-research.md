# 横截面因子研究记录（诚实版）

> 目标：找出能过**严格样本外验证**的真实预测信号。验收标准统一：滚动起点 CV / 点-时 +
> **按日期分块自助 95% CI**（吸收截面相关），CI 排除 0 才算真。绝不信单次 70/30 切分或看图。

## 二、成立的真信号

### 1. 12−1 月横截面动量（价量唯一 edge）
多样化 34 标的：持有 21 日 spread +0.32%（CI [+0.03,+0.61]）；持有 63 日 +0.72%（CI [+0.24,+1.22]）。
风险调整版≈裸动量（无改进）；纯大盘池里偏弱。`scripts/test-xs-momentum.ts`

### 2. 价值（账面/市值 B/M）——第一个和动量正交的真信号
SEC EDGAR **point-in-time**（filed≤d，无重述/滞后泄漏）× 价格，53 家大盘：
B/M spread **+0.51%/63d，CI [+0.11,+0.92]，P>0=99%**。便宜的跑赢贵的（价值溢价）。
注：质量（ROE、GP/A）在本大盘池**反向**（高质量=贵→跑输）；盈利收益率(E/P)不显著。

### 3. ⭐ 价值 + 动量（本研究的"工业级"落点）
`z(B/M) + z(mom)`，等权、理论驱动（Asness "Value & Momentum Everywhere"），不调参：
**spread +0.91%/63d，CI [+0.44,+1.41]，P>0=100%**，且**三个子时段全为正**：

| 段1 09–15 | 段2 15–20 | 段3 20–26 |
|---|---|---|
| +0.63% | +0.77% | +1.34% |

**为何稳健**：价值单独在 2015–2020 翻负（−0.96%，价值失落期），但动量在同期把组合托住（+0.77%）——
value 与 momentum 负相关，组合在任一失灵时仍正。这是多因子分散的核心。`scripts/test-fund-factors.ts valmom`

### 4. ⭐ 前瞻波动率预测（与"方向不可预测"相反的一面）
**方向≈随机游走，但波动会聚集且向长期均值回归**——金融里最稳的可预测量。
`log(未来H日已实现波动) ~ log(近look日已实现波动)` 线性拟合，扩窗滚动起点 CV：
**池化 OOS R²=0.62，6/6 折全为正，rankIC≈0.72，斜率稳定≈0.77（<1=均值回归）**。
`scripts/test-vol-forecast.ts`（`pnpm model:vol-test`）。
已上线：`src/lib/signals/position.ts:forwardVolForecast`（点-时自拟合，对 live 最新一根无未来函数）
→ 详情页"波动预测（未来20日）"状态：预测年化波动 + 分位 + **反波动仓位建议**（目标=该股常态波动→1×）。
这是模型里**第一个真正前瞻、且对"用多大仓位进场"直接可操作**的输出（方向概率做不到的事）。

## 三、诚实定位
- 这是个**真实、稳健、无泄漏、理论驱动**的多因子横截面模型——工业级量化股票的地基。
- 但量级**温和**：~0.9%/63d 多空（毛）≈ 0.43%/月。作为可交易多空在成本后边际；作为**给股票排序的横截面信号 / 判断辅助**站得住。
- 刻意不纳入样本内挑出的"做空质量"（+1.16% 但数据窥探，不诚实）。
