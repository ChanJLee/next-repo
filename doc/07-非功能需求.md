## 7.2 可用性

### 7.2.1 SLA

| 部署形态 | SLA |
|---------|------|
| 公有云 SaaS（标准） | 99.9%（年停机 ≤ 8.7h） |
| 公有云 SaaS（高级） | 99.95%（年停机 ≤ 4.4h） |
| 私有化（高可用） | 99.9% |

### 7.2.2 容灾

- 同城双活：核心业务模块支持同城双机房部署
- 异地灾备：每日全量备份 + 每小时增量，异地保留 30 天
- RTO（恢复时间目标）：≤ 1 小时
- RPO（数据丢失目标）：≤ 15 分钟

### 7.2.3 农忙保障

农忙期间（夏收 / 秋收）业务量峰值显著，需特别保障：

- 农忙前 2 周完成压测 + 容量预扩
- 农忙期间运维 7×24 值班
- 关键功能（开单、出库、工单）单独熔断，避免被报表等耗时操作拖垮
- 离线模式兜底：服务工程师 / PDA 必须可在弱网下完成核心操作

### 7.2.4 降级策略

| 故障情形 | 降级 |
|---------|------|
| 全文检索 ES 不可用 | 降级到数据库 LIKE 查询 |
| 物流接口超时 | 单据保留，物流号后台异步重试 |
| 整机厂 DMS 不可用 | 三包索赔进入本地待提交队列，恢复后批量上送 |
| 报表服务故障 | 显示缓存数据 + 服务异常提示 |
| Kafka 不可用 | 关键事件落库本地表，Kafka 恢复后补偿投递 |

## 7.3 安全

### 7.3.1 网络安全

- 全站 HTTPS（TLS 1.2+）
- 内部服务间 mTLS（私有化部署可选）
- WAF 防 SQL 注入 / XSS / CSRF
- DDoS 防护（云上由云厂商提供）
- 内网与外网严格隔离，仅必要端口暴露

### 7.3.2 数据安全

- 数据库连接 SSL 加密
- 敏感字段（身份证、银行卡）数据库层加密存储（AES-256）
- 备份文件加密
- 密码使用 bcrypt（cost ≥ 12）
- API 请求签名（防篡改）

### 7.3.3 身份与权限

详见 [05 角色权限](./05-角色权限.md)

- 强密码策略：长度 ≥ 8、含大小写字母数字、有效期 90 天
- 二次验证：管理员、财务等关键角色强制开启
- 单设备登录可配置（SaaS 默认允许多设备）
- 越权检测：每次请求服务端校验数据归属

### 7.3.4 审计与合规

- 所有写操作 + 关键查询写审计日志，保留 ≥ 6 个月（云上）/ ≥ 2 年（私有化）
- 个人信息保护：符合《个人信息保护法》、客户身份证 / 联系方式脱敏展示
- 数据出境：私有化部署默认不出境
- 日志中禁止打印密码、token、银行卡明文

### 7.3.5 漏洞响应

- 公开高危漏洞 24 小时内出补丁
- 中危漏洞 7 天内修复
- 安全扫描：每周自动 + 每季人工渗透
- 应急预案：明确角色与升级路径

## 7.4 可维护性

### 7.4.1 代码质量

- 代码评审：所有合并必经 1+ 评审
- 单元测试覆盖率 ≥ 70%（核心业务模块 ≥ 85%）
- 集成测试：关键业务流程端到端覆盖
- 静态扫描：SonarQube，质量门禁强制通过

### 7.4.2 文档要求

- 接口文档：OpenAPI 自动生成 + 业务说明
- 数据库变更：所有 schema 变更通过 Flyway / Liquibase 版本管理
- 运维手册：部署、扩容、备份、回滚、应急预案
- 业务文档：本套产品文档，随版本更新

### 7.4.3 升级与迁移

- 数据库变更：向前兼容（先发新代码兼容老结构 → 升级数据 → 老代码下线）
- 客户端版本：服务端兼容近 3 个版本，强制升级走灰度
- 数据迁移工具：Excel / 老系统数据库一键导入，向导式映射

## 7.5 易用性

### 7.5.1 用户体验

- 关键操作（开单、出库、工单）流程 ≤ 5 步
- 移动端单手操作友好
- 操作反馈即时（< 200ms 视觉反馈）
- 错误提示明确：错在哪、为什么、如何修复

### 7.5.2 适配场景

- Web：1366×768 起，主流浏览器（Chrome、Edge、Safari）近 2 版
- 移动 App：iOS 14+、Android 8+
- PDA：Android 7+，主流工业 PDA 品牌（Honeywell、Zebra、新大陆）
- 弱网：3G 环境可用，离线模式核心功能可用

### 7.5.3 国际化与本地化

- V1 中文（简体），日期、货币使用 GMT+8 / CNY
- V2 预留多语言、多币种、多时区扩展点（资源文件 + 国际化函数）

### 7.5.4 帮助与培训

- 内置帮助中心：常见问题、视频教程
- 新手引导：首次登录引导浏览
- 在线客服：工作时间 9–21 点，工单系统兜底
- 实施服务：标准实施周期 2–6 周，含培训

## 7.6 可扩展性

### 7.6.1 水平扩展

- 应用层无状态，K8s HPA 自动扩缩容
- 数据库读写分离，读副本可扩
- 大客户独立实例，资源隔离

### 7.6.2 业务可扩展

- 单据自定义字段（扩展属性 jsonb）
- 流程可视化设计（审批流、单据状态机）
- 报表自定义（拖拽设计器）
- 插件机制：业务规则插件化（如价格计算、补货建议算法）

### 7.6.3 集成可扩展

- 开放 API + Webhook，支持第三方接入
- ETL 工具：与外部系统数据互通
- 适配器模式：新增物流 / 财务 / 整机厂对接，独立适配器即插即用

## 7.7 合规

### 7.7.1 行业合规

- 农机三包：依据《农业机械产品修理、更换、退货责任规定》设计三包流程与时限
- 政府补贴：依据《农业机械购置补贴实施方案》台账与凭证留存要求
- 增值税：发票开具符合金税四期要求

### 7.7.2 等保

- 公有云 SaaS：等保 2.0 三级
- 私有化部署：客户自评估，提供配置指南

### 7.7.3 数据保护

- GDPR / PIPL（个人信息保护法）合规
- 客户数据归客户所有，平台仅作处理者
- 数据导出：客户可一键全量导出
- 账号注销：清理或匿名化个人数据

## 7.9 实施与交付标准

### 7.9.1 实施流程

1. 需求调研（1–2 周）
2. 主数据准备（客户提供 / 协助导入，1–2 周）
3. 系统配置（流程、权限、单据规则，1 周）
4. 培训（管理员 + 业务，3–5 天）
5. 试运行（1–2 周，并行旧系统）
6. 切换上线
7. 后续支持（前 2 周强支持，1 个月内 SLA 缩短至 4 小时）

### 7.9.2 验收标准

- 功能验收：核心场景测试用例 100% 通过
- 性能验收：达到 [7.1](#71-性能) 中目标
- 数据验收：迁移数据准确率 ≥ 99.99%，关键单据 100% 一致
- 培训验收：核心岗位用户独立完成日常操作
