# 01 产品概述

## 1.1 行业背景

农机配件流通是一个低频、高客单、强季节、重服务的行业，与汽配相比有几个鲜明特征：

1. **设备生命周期长**：一台拖拉机/收割机使用 8–15 年，期间需多次更换易损件，存量市场远大于新机市场
2. **机型分散**：国内主流品牌 30+，机型 1000+（仅约翰迪尔、雷沃、东方红、沃得、久保田几家就覆盖数百型号），单一机型的配件适配难度高
3. **农时即生命线**：错过夏收（约 10–15 天窗口）一台收割机停机一天可能损失数千亩订单，配件供应有"农忙不能停"的硬性要求
4. **网络下沉**：客户多在县、乡、村，物流、服务、回款都需深入末端，纯线上模式难以覆盖
5. **三包政策严格**：原厂件三包为国家强制要求，索赔需走整机厂流程，单据完整性是经销商收益的关键
6. **政策驱动**：农机购置补贴、报废更新等政策直接影响销售与售后节奏，台账要求高
7. **跨区作业**：收割机随麦收/稻收季节南北转场，配件需跟随机器跨省追配

行业内现状是大量经销商仍依赖手工台账、Excel、微信群对账，导致库存积压、错发漏发、索赔流失、回款拖延普遍。

## 1.2 目标用户

| 用户类型 | 规模 | 典型痛点 |
|---------|------|---------|
| 农机经销商（一级 / 二级） | 5–200 人 | 多机型 SKU 杂乱、农忙缺货、滞销积压、欠款多 |
| 整机厂区域售后中心 | 20–100 人 | 三包索赔台账复杂、备件下发到下级网点不透明 |
| 农机合作社 | 5–50 人 | 自有机器多、保养记录乱、跨区作业配件难追配 |
| 县乡农机服务站 | 1–10 人 | 简单易用、移动开单、配件查询、上门服务记录 |
| 大型种植农场企业 | 自有机队 50–500 台 | 资产管理、保养排程、年度配件预算、库存共享 |

## 1.3 产品定位

> **一套系统覆盖农机配件从备货到售后的全部业务，按机型卖配件，按农时排库存，按三包做服务。**

- **行业属性深**：原生机型库、配件适配关系、三包政策、农时日历、保养周期
- **业务闭环全**：采购 → 入库 → 库存 → 销售 → 出库 → 售后/三包 → 应收/应付 → 报表
- **多端协同**：Web 后台 + 移动 App（开单、扫码、上门服务） + 小程序（终端客户查机器、报修、买件）
- **可下沉**：支持总部 / 区域 / 县乡店多级组织，弱网/离线场景可用
- **可成长**：基础版到旗舰版，支持多组织、多仓、多币种、跨区调拨

## 1.4 核心价值

### 1.4.1 对老板 / 经营者

- 实时掌握销售、库存、毛利、应收应付，手机端经营驾驶舱
- 滞销 / 缺货 / 临农忙 / 欠款客户多维预警
- 多店多仓数据合并，总部统一采购、调拨、补贴申报

### 1.4.2 对采购员

- 按机型 + 农时季节 + 销售历史自动生成补货建议
- 整机厂供货、品牌件、副厂件三类供应商一站管理
- 询价单群发、报价对比、交期 / 合格率绩效自动评分

### 1.4.3 对销售 / 开单员

- 输入机型 / 出厂编号即可筛出适配配件
- 三包件销售自动登记三包卡，避免漏开漏录
- 支持赊销、月结、政府补贴单结算

### 1.4.4 对售后 / 服务工程师

- 客户机器档案：购买信息、历史维修、保养周期
- 工单移动端接单、上门、拍照、签字、收款、生成三包索赔
- 农忙期值班排程、应急备件就近调度

### 1.4.5 对仓库

- 移动端 PDA 扫码出入库
- 库位 / 批次管理，三包件序列号追溯
- 农忙前盘点向导、农忙后差异核销

### 1.4.6 对财务

- 销售单 / 采购单 / 索赔单自动生成应收应付
- 政府补贴款单独台账，便于审计
- 与税控、银企直连、记账软件集成

## 1.5 业务场景示例

### 场景 A：夏收前的备货与售卖

> 5 月底，麦收即将启动。某经销商主营雷沃 GE80 收割机配件。

1. 系统按"过去 3 年同期销售 + 在用机器存量 + 当前库存 + 安全库存"自动生成补货建议清单
2. 采购员一键发询价单给 3 家供应商（雷沃原厂、品牌副厂 A、品牌副厂 B），系统比价后下单
3. 6 月 1 日麦收启动，某农机手电话报修：割台传动皮带断了。销售扫描机器铭牌二维码，系统识别机型，过滤适配的皮带 SKU 共 2 个（原厂 / 品牌副厂），客户选品牌副厂
4. 仓库发货 + 派服务车上门安装，2 小时内完成
5. 系统自动生成销售单 + 上门服务工单 + 客户机器维修记录

### 场景 B：三包索赔

> 一台去年新购的东方红拖拉机 LX904 在保修期内变速箱异响。

1. 客户通过小程序报修，系统调出机器档案：2025-08-12 购买、整机三包至 2027-08-12、关键部件三包至 2028-08-12
2. 服务工程师上门拆检，确认变速箱二轴轴承损坏（属三包范围）
3. 工单录入故障代码、故障件、更换件、工时，拍照上传
4. 系统自动生成三包索赔单，附故障件返厂物流信息
5. 三包索赔单流转：经销商 → 区域售后中心 → 整机厂总部
6. 整机厂审核通过后回款，系统自动核销

### 场景 C：跨区作业的配件追配

> 一支收割机队从河南转场到山东，途中一台机器液压油缸密封件损坏。

1. 机手通过客户小程序填写当前位置（GPS）+ 机型 + 故障件
2. 系统按"距离最近 + 库存充足"原则匹配到山东菏泽的合作经销商
3. 自动生成跨区调拨/代发单：菏泽店发货，原服务商承担成本，整机厂结算回扣
4. 配件 4 小时送达，机器恢复作业

### 场景 D：保养提醒

> 客户的久保田 PRO688Q 收割机已工作 480 小时，距 500 小时大保还差 20 小时。

1. 系统按工作小时模型计算，提前 10% 触发提醒
2. 自动生成保养预订单：保养所需机滤、空滤、燃滤、液压油、机油、冷却液
3. 客户小程序收到通知，确认上门保养时间
4. 服务工程师上门，按清单更换并录入工时数据，下次保养自动累计

## 1.6 产品边界

**包含**：

- 配件主数据、机型库、客户档案、客户机器档案、供应商档案
- 询价、采购、入库、库存、销售、出库、退货、调拨、盘点
- 服务工单、上门服务、保养计划、三包索赔
- 应收应付、对账、付款、收款、成本核算、政府补贴台账
- 多组织、多仓、多门店
- 报表与经营分析

**不包含（V1）**：

- 整机销售（按整机销售流程，单独子系统，V2 提供）
- 全套财务总账（提供凭证导出，对接金蝶 / 用友）
- 自有商城前端（提供 API，由外部商城接入）
- 农机金融 / 融资租赁（V2 评估）

## 1.7 与其他系统的边界

| 上游 / 下游 | 关系 |
|----------|------|
| 整机厂 ERP / DMS | 下游，接收备件订货、上传三包索赔、补贴台账 |
| 整机厂 CRM | 联动，客户机器档案双向同步 |
| 物流系统（顺丰、跨越、德邦） | 调用，发货 / 跨区调拨 / 故障件返厂 |
| 财务系统（金蝶、用友） | 推送凭证，不做总账 |
| 税控系统（百望、航信） | 推送开票，不做发票打印机驱动 |
| 银企直连 | 收款自动核销 |
| 政府农机补贴系统 | 数据填报与凭证保留（不直接对接） |
