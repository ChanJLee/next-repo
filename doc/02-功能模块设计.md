## 2.2 经营驾驶舱（首页）

按角色显示不同卡片，老板默认看全局，区域负责人看区域。

**核心指标卡**：
- 今日 / 本月销售额、销售单数、毛利（同环比）
- 待发货 / 待入库 / 待审核 / 待回访工单数
- 库存总值、滞销库存、缺货 SKU 数
- 应收总额、逾期应收、应付总额
- 在保机器数、本月待保养机器数、未结三包索赔数

**农时提示条**（顶部强提醒）：
- 距春耕 / 夏收 / 秋收开始天数
- 高峰期备货达标率（实际库存 / 建议库存）

**图表区**：
- 近 30 天销售趋势（按日，可切毛利 / 按机型 / 按品牌）
- 销售排行 TOP 10（按 SKU、客户、机型）
- 库存周转 TOP / BOTTOM 10
- 客户欠款 TOP 10

**待办区**：
- 我的审批
- 安全库存预警
- 临期机滤 / 油液保质期预警
- 客户保养到期、三包索赔需跟进

## 2.3 基础数据

### 2.3.1 配件主数据（核心）

**关键字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 配件编码 | string(32) | 是 | 内部唯一编码，规则可配置 |
| 配件名称 | string(128) | 是 | 显示名称 |
| 厂家件号 | string(64) | 否 | 整机厂原厂件号 |
| 替换件号 | string(64)[] | 否 | 多个，互查用 |
| 分类 | tree | 是 | 三级，如 发动机系 / 滤清器 / 机油滤芯 |
| 适配机型 | 多选 | 否 | 关联机型库（多对多） |
| 品牌 | enum | 是 | 关联品牌字典 |
| 件类 | enum | 是 | 原厂件 / 品牌件 / 副厂件 |
| 三包属性 | enum | 是 | 三包件 / 易损件 / 非三包 |
| 三包期 | int | 否 | 月数，对接整机厂政策 |
| 计量单位 | enum | 是 | 个、套、对、米、升、桶 |
| 辅助单位 | enum | 否 | 用于换算（1 桶 = 18 升） |
| 默认仓库 | enum | 否 | 默认入库仓 |
| 默认供应商 | ref | 否 | 主供应商 |
| 采购参考价 | decimal | 否 | 进货指导价 |
| 销售指导价 | decimal | 否 | 零售 / 批发指导价 |
| 安全库存 | int | 否 | 低于此值预警 |
| 农时季节系数 | json | 否 | {"春耕":1.5,"夏收":2.0,"秋收":1.8} |
| 是否管控批次 | bool | 否 | 油液 / 滤芯类 |
| 是否管控序列号 | bool | 否 | 高价值件 / 三包主件 |
| 保质期 | int | 否 | 天数，0 为无 |
| 启用状态 | enum | 是 | 启用 / 停用 |

**核心能力**：

- **替换件互查**：原厂件号、品牌副厂件号互相映射，按任一编码搜索可找到所有可替代项
- **机型适配**：SKU ↔ 机型多对多关系，前端按机型反查可售配件
- **三包属性**：三包件、易损件、普通件分类，决定销售时是否强制开三包卡
- **农时季节系数**：补货建议算法直接读取，按当前农时阶段动态调整安全库存
- **图片管理**：每个 SKU 多图，含主图、细节图、安装位置图、损坏对比图
- **批量导入**：Excel 模板导入，校验失败行高亮 + 错误提示

### 2.3.2 机型库

| 字段 | 说明 |
|------|------|
| 品牌 | 雷沃、约翰迪尔、东方红、久保田、沃得、星光… |
| 厂商 | 雷沃重工、一拖、洋马农机… |
| 大类 | 拖拉机 / 收割机 / 插秧机 / 烘干机 / 植保机 / 其他 |
| 系列 | 雷沃欧豹、约翰迪尔 5E、东方红 LX… |
| 型号 | LX904、5E-954、PRO688Q… |
| 出厂年份范围 | 2018–2024 |
| 发动机型号 | 关联发动机字典 |
| 主要参数 | 功率、马力、轮距、作业幅宽 |
| 整机厂三包政策 | 关联三包政策字典 |
| 出厂铭牌格式 | 用于扫码识别 |

支持铭牌二维码扫码识别：扫描机器铭牌二维码 → 解析机型 + 出厂编号 → 自动匹配机型档案。

### 2.3.3 客户档案

- 基本信息：客户编码、名称、类型（个体农户 / 农机大户 / 合作社 / 农场企业 / 修理厂 / 经销商）、联系人、电话、地址、所在县乡村
- 业务信息：默认价格策略、信用额度、账期、对账日、所属销售
- 分级：普通、银卡、金卡、VIP
- 多联系人：每个客户多个联系人
- 收货地址簿
- 关联机器：客户名下所有农机（见 2.3.4 客户机器档案）
- 客户档案视图：合并显示交易、欠款、积分、跟进、维修历史

### 2.3.4 客户机器档案（重要）

不同于汽车，农机一台机器价值高、生命周期长，需要做"机器一档"：

| 字段 | 说明 |
|------|------|
| 机器编号 | 内部唯一编号 |
| 客户 | 关联客户 |
| 机型 | 关联机型库 |
| 出厂编号 | 整机厂铭牌号（VIN 类） |
| 发动机号 | 用于三包追溯 |
| 出厂日期 | 整机出厂 |
| 购机日期 | 客户购买日期，决定三包起算 |
| 购机来源 | 本店 / 外购 |
| 整机三包到期 | 自动计算 |
| 关键件三包到期 | 自动计算（如发动机三年） |
| 当前作业小时 | 累计工作小时 |
| 当前作业亩数 | 累计作业亩数（收割机用） |
| 上次保养日期 | 同步自最近一次工单 |
| 下次保养预计 | 按保养计划自动算 |
| 维修历史 | 关联工单 |
| 配件更换历史 | 自动归集 |

### 2.3.5 供应商档案

- 基本信息：编码、名称、税号、银行账户、联系人
- 类型：整机厂直供 / 一级代理 / 品牌副厂 / 区域贸易商
- 业务信息：默认账期、付款方式、交期、币种
- 评分：质量、价格、交期、服务四维（销售 / 采购自动打分 + 人工评估）
- 黑名单：一键标记

### 2.3.6 仓库与库位

- 仓库：编码、名称、类型（自有 / 寄售 / 在途 / 不良品 / 三包返厂中转）、地址、负责人、覆盖区域
- 库位：仓库 → 区 → 排 → 货架 → 库位号
- 库位规则：可指定 SKU 默认库位、ABC 分类自动分库位

### 2.3.7 价格策略

- 客户分级价
- 客户专属价
- 阶梯价（数量越大单价越低）
- 促销价（带生效时间窗，常用于淡季促销）
- 农时差异价（如夏收期间应急服务价）
- 优先级：客户专属 > 促销 > 阶梯 > 客户分级 > 标准价

### 2.3.8 农时日历（行业特色）

可视化日历，按地区配置春耕 / 夏收 / 秋收 / 冬储四个阶段的起止时间。例：

| 区域 | 阶段 | 时间 | 影响 |
|------|------|------|------|
| 黄淮海 | 夏收 | 5/25 – 6/15 | 收割机配件备货系数 ×2.0 |
| 黄淮海 | 秋种 | 6/10 – 6/30 | 拖拉机配件备货系数 ×1.5 |
| 东北 | 秋收 | 9/15 – 10/20 | 大型收割机件 ×1.8 |
| 长江中下游 | 双抢 | 7/15 – 8/15 | 插秧机 + 收割机件 ×1.6 |

农时日历直接驱动补货建议、销售排程、值班安排。

## 2.4 采购管理

### 2.4.1 询价单

- 多供应商一键群发询价
- 供应商通过链接 / 小程序回填报价
- 系统自动比价表，标记最低价、综合最优（价 + 交期 + 历史合格率）
- 可基于询价单生成采购订单

### 2.4.2 采购订单

- 字段：单号、供应商、收货仓、币种、汇率、明细行（SKU、数量、单价、税率、交期）、合计、备注
- 状态机：草稿 → 待审核 → 已审核 → 部分入库 → 已入库 → 已关闭
- 农忙备货专项：可批量基于补货建议清单生成
- 支持拆单：一张订单分批入库

### 2.4.3 收货入库

- 基于采购订单生成收货单
- 支持完全收货 / 部分收货 / 超量收货（按权限放行）
- 扫码入库：PDA 扫码 SKU 条码、批次号、序列号
- 三包件入库强制录序列号（用于后续追溯）
- 入库后自动生成库存流水、应付凭证

### 2.4.4 采购退货

- 基于入库单退货：质量退、过量退、过期退
- 退货后冲减应付，或进入应收换货

### 2.4.5 供应商对账

- 按周期生成对账单
- 支持供应商在线确认（小程序签字）
- 对账确认后才允许付款

## 2.5 库存管理

### 2.5.1 入库 / 出库单

集中入口，含所有出入库类型：

- 入库类型：采购入库、销售退货入库、调拨入库、盘盈、三包返修入库、其他
- 出库类型：销售出库、采购退货出库、调拨出库、盘亏、领用、报损、三包返厂出库

### 2.5.2 库存查询

- 多维度：按 SKU / 仓库 / 库位 / 批次 / 序列号
- 实时数量：现存量 = 账面量 − 已分配 − 已锁定 + 在途
- 库龄分析：0-30 / 31-90 / 91-180 / 180+ 天
- 联动查询：点 SKU 跳转最近 30 天出入库流水

### 2.5.3 库存盘点

**三种模式**：

- **全盘**：年度大盘，全仓暂停作业
- **抽盘**：随机抽取 N 个 SKU 或某区域
- **循环盘点**：按 ABC 分类，A 类月盘、B 类季盘、C 类年盘
- **农忙前盘点向导**：进入农忙前必盘 SKU 自动筛选（高频销售 + 三包件）

**流程**：

1. 生成盘点单（冻结相关 SKU 的可用量）
2. PDA 扫码录入实物数量
3. 系统对比账面，生成差异表
4. 复盘 → 审核 → 自动生成盘盈 / 盘亏单

### 2.5.4 库存调拨

- 同公司不同仓库间调拨：发出 → 在途 → 接收
- 跨公司（连锁总分店）调拨：按内部成本价结算

### 2.5.5 跨区代发（行业特色）

农机跨区作业时，机器跑到外地报修，本地缺件需当地经销商代发：

- 客户机器位置（GPS）+ 故障件 → 系统按距离 + 库存匹配最近合作经销商
- 自动生成跨区代发单：代发方出库、原服务方记账
- 月底自动结算（含代发服务费）

### 2.5.6 农忙备货建议

- 基于"过去 3 年同期销售 + 在用机器存量 + 当前库存 + 农时季节系数"
- 输出建议清单：SKU、建议数量、建议供应商、预估金额
- 一键生成多张采购订单

### 2.5.7 保质期 / 库龄预警

- 临期预警：油液类、滤芯类，保质期 ≤ 30 天高亮，可触发自动促销
- 滞销预警：90 天无销售自动标记滞销
- 安全库存预警：现存量 ≤ 安全库存触发

## 2.6 销售管理

### 2.6.1 报价单

- 销售员对外报价文档，PDF / 图片导出，微信发送
- 客户确认后一键转销售订单

### 2.6.2 销售订单

- 字段：客户、关联机器、销售员、收货地址、明细行（SKU、数量、单价、折扣、税率）、合计、付款方式、备注
- 状态机：草稿 → 待审核 → 已审核 → 部分发货 → 已发货 → 已关闭
- **机型选择器**：先选客户机器或机型，系统过滤适配 SKU
- **三包件登记**：销售三包件时强制录入对应客户机器、出厂编号
- **价格保护**：低于成本价、低于最低售价时弹出审批
- **信用控制**：超信用额度禁止下单或走特批
- **政府补贴单**：标记为补贴销售时，自动校验政策、生成台账记录

### 2.6.3 销售出库

- 自动按订单生成拣货任务
- PDA 扫码出库，扫错件提示
- 支持一单分多次发货
- 出库后扣减库存、生成应收

### 2.6.4 销售退货

- 基于销售单退货
- 强制选择退货原因（用于售后分析）
- 三包件退货特殊流程：先入"待返厂仓"，再走三包索赔

### 2.6.5 客户对账与回款

- 月结对账单自动生成
- 客户在小程序确认对账
- 收款单：现金 / 银行 / 微信 / 支付宝 / 抵扣预收 / 政府补贴款
- 自动核销最早未收款单据（先进先出）

## 2.7 服务与售后（行业核心）

### 2.7.1 服务工单

- 触发渠道：客户小程序报修、电话报修、销售上报、保养自动生成
- 字段：客户、关联机器、故障描述、故障代码、当前作业小时、当前位置（GPS）、紧急程度、期望上门时间
- 状态机：待派单 → 已派单 → 已接单 → 服务中 → 待审核 → 已完成 → 已关闭

### 2.7.2 上门服务调度

- 服务工程师视图：今日工单看板、地图视图（按 GPS 聚合）
- 农忙期值班排程：自动检测农忙期，一键启用 24h 应急排班
- 派单算法：距离优先、工程师技能匹配、当前负载

### 2.7.3 工单移动端

- 工程师 App：接单 → 上门定位打卡 → 拍照（故障件、铭牌、损坏部位） → 录入故障原因 + 更换件清单 → 客户签字 → 收款（现金 / 微信 / 支付宝）→ 关单
- 离线模式：弱网环境数据本地缓存，恢复后自动同步

### 2.7.4 客户机器档案联动

- 工单完成自动写入机器维修历史
- 自动累加工作小时、亩数（按工单输入）
- 自动重算下次保养预期日期

### 2.7.5 保养计划与提醒

- 按机型预设保养标准（500h / 1000h / 1500h / 2000h 大保养及对应配件清单）
- 系统按机器当前小时数 + 标准小时数计算下次保养
- 提前 10–20% 推送提醒，自动生成保养预订单
- 客户小程序确认 → 工程师上门 → 工单核销

### 2.7.6 三包索赔（行业核心）

**字段**：

| 字段 | 说明 |
|------|------|
| 索赔单号 | 自动生成 |
| 客户 / 机器 | 关联档案 |
| 故障件 SKU | 三包件清单 |
| 故障描述 | 文字 + 图片 |
| 故障件序列号 | 必填 |
| 更换件 SKU | 关联出库单 |
| 工时 | 数值 |
| 索赔金额 | 件 + 工时 |
| 整机厂政策 | 自动匹配 |
| 状态 | 待提交 → 区域审核 → 总部审核 → 通过 / 驳回 → 已结算 |

**故障件返厂**：

- 索赔通过后，故障件需返厂（部分政策）
- 系统生成"故障件返厂出库单"，对接物流
- 返厂签收后自动核销

**驳回处理**：

- 驳回原因记录
- 可补充资料重新提交
- 累计驳回率作为经销商绩效

## 2.8 财务管理

### 2.8.1 应收应付

- 应收：每张销售出库单生成一条
- 应付：每张采购入库单生成一条
- 三包索赔应收：单独账目，按整机厂结算周期跟进
- 政府补贴应收：单独账目，台账完整性单独管理
- 老化分析：未到期 / 0-30 / 31-60 / 61-90 / 90+ 天

### 2.8.2 收款 / 付款

- 多种支付方式
- 一笔款项核销多张单据
- 支持预收预付

### 2.8.3 政府补贴台账

- 每张涉及补贴的销售单单独记录：政策类型、补贴比例、客户身份证、机器出厂号、补贴金额、申报状态
- 台账完整性校验：申报缺失字段一键查
- 凭证留存：身份证、户口本、银行卡、申请表扫描件

### 2.8.4 成本核算

- 三种方法（按 SKU 设置）：加权平均、移动加权、先进先出
- 成本调整：发现历史成本错时反向追溯重算

### 2.8.5 发票管理

- 销项发票：与销售单关联，对接税控
- 进项发票：扫码识别录入
- 红冲、作废流程

## 2.9 报表与分析

### 2.9.1 销售分析

- 销售汇总：按时间、客户、销售员、SKU、品牌、机型、农时阶段
- 毛利分析：单据 / 商品 / 客户级毛利
- 客户排行：销售额、毛利、回款率
- 销售员业绩：开单数、销售额、毛利、回款率、提成

### 2.9.2 库存分析

- 库存余额表
- 库存收发存
- 库龄分析、周转率、ABC 分析
- 滞销 / 缺货报表
- 农忙备货达标率

### 2.9.3 采购分析

- 采购汇总：按供应商、SKU、品类
- 价格波动：同 SKU 历史采购价趋势
- 供应商绩效：交期达成率、合格率、退货率

### 2.9.4 售后分析

- 工单数 / 完工率 / 平均响应时长
- 故障件 TOP（指导备件备货）
- 工程师产能、客户满意度评分

### 2.9.5 三包分析

- 索赔金额、通过率、驳回原因 TOP
- 故障件 TOP（向整机厂反馈质量问题）
- 区域售后中心绩效

### 2.9.6 财务报表

- 应收 / 应付账龄表
- 资金日报、月报
- 政府补贴申报台账
- 凭证导出（金蝶、用友、SAP 格式）

### 2.9.7 自定义报表

- 拖拽式报表设计器
- 支持订阅：定时邮件 / 钉钉 / 微信 / 短信推送

## 2.10 系统管理

- **组织架构**：集团 / 公司 / 区域 / 县乡店
- **用户管理**：账号、绑定手机 / 邮箱、密码策略、二次验证
- **角色权限**：菜单 / 按钮 / 字段 / 数据权限（按组织 / 部门 / 个人 / 客户）
- **审批流**：可视化流程设计器，按单据类型 + 金额 + 部门配置
- **单据编号规则**：可视化配置（前缀 + 日期 + 流水号）
- **操作日志**：所有写操作记录，按用户 / 单据 / 时间检索
- **参数配置**：业务开关（如允许负库存、强制三包登记等）
- **数据字典**：枚举字典统一管理
