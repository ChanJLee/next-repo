# 03 业务流程

本章节描述系统中的关键业务流程，每个流程包含：参与角色、前置条件、步骤、单据流转、异常处理。

## 3.1 流程总览

```
   配件主数据 ──┐
   机型库     ──┼──→ 询价 → 采购订单 → 收货入库 → 库存
   供应商档案 ──┘                                  │
                                                   ↓
   客户档案 ──┐                              销售订单 → 销售出库
   客户机器 ──┼──→ 报价 ────────────────────→     ↓
   价格策略 ──┘                              客户对账 → 收款
                                                   │
   服务工单 ──→ 上门服务 ──→ 故障件返厂 ──→ 三包索赔 → 整机厂结算
                            │
                            └─→ 配件销售 ──→ 销售出库
```

## 3.2 配件主数据维护流程

**参与者**：商品 / 数据管理员

**前置条件**：机型库、品牌、分类、供应商已建立

**步骤**：

1. 新增 SKU：录入编码、名称、分类、品牌、单位、件类、三包属性等
2. 关联适配机型：勾选适配的机型清单
3. 关联替换件：录入原厂件号、品牌副厂件号互查关系
4. 设置库存策略：默认仓库、安全库存、最大库存、农时季节系数
5. 设置定价：采购参考价、销售指导价
6. 上传图片
7. 提交审核（如开启审批流）→ 启用

**单据流转**：草稿 → 已启用 / 已停用

**异常处理**：

- 重复编码：拒绝保存
- 引用关系存在时停用：警示但允许停用，已开单据保留

## 3.3 农忙备货流程

**参与者**：采购员、采购主管、仓库

**前置条件**：销售历史 ≥ 1 年；农时日历配置

**步骤**：

1. 系统在农时阶段开始前 30 天（默认值）自动生成补货建议
2. 计算公式：建议数量 = max(过去 3 年同期销售均值 × 农时系数, 安全库存) − 当前现存量 − 在途量
3. 采购员复核建议清单，调整数量、选定供应商
4. 一键生成多张采购订单（按供应商分组）
5. 询价 / 议价（如需）→ 订单审批 → 下单
6. 供应商发货 → 仓库收货入库
7. 入库后系统自动核对到货率，对未达标的订单触发催货提醒

**异常处理**：

- 供应商交期不达预期：自动改派备选供应商或拆单
- 历史数据不足：使用区域同类机型销售均值替代

## 3.4 标准销售流程

**参与者**：销售员、仓库、客户、财务

**步骤**：

1. **接单**：客户电话 / 微信 / 小程序询单
2. **车机识别**：销售扫描客户机器铭牌或选择客户机器档案，确定机型
3. **配件筛选**：系统按机型过滤适配 SKU，显示库存、价格
4. **报价**：生成报价单 → 客户确认（PDF / 微信）
5. **下单**：报价转销售订单 → 系统自动校验信用额度、最低售价
6. **审批**（如需）：金额超限 / 折扣过低进入审批流
7. **拣货出库**：仓库 PDA 接收任务 → 扫码出库 → 三包件强制录序列号
8. **物流发货**：自有车队 / 第三方物流，回传单号
9. **客户签收**：物流签收回写
10. **生成应收**：销售出库自动生成应收账款
11. **回款**：客户付款 → 自动核销

**异常分支**：

- 库存不足：可拆单（部分发货 + 缺货后续补发） / 拒单 / 调拨补货
- 客户欠款超额：阻断下单或走特批
- 三包件登记缺失：阻断出库

## 3.5 三包件销售流程（特殊）

**参与者**：销售员、仓库、客户

**步骤**：

1. 选定 SKU 时系统识别为三包件，弹出强制登记页
2. 必填：客户机器（关联档案）、机器出厂号、发动机号、当前作业小时
3. 销售订单审批通过 → 出库时强制扫描配件序列号
4. 系统自动生成"三包件销售记录"，与客户机器档案绑定
5. 后续如发生故障，可凭此记录发起索赔

**关键校验**：

- 三包件必须关联客户机器
- 序列号必须与入库时一致
- 客户机器三包到期日必须在销售时校验

## 3.6 服务工单全流程（含上门）

**参与者**：客户、客服、调度员、服务工程师、仓库

```
 客户报修 ──┬─ 小程序填报 ─┐
           ├─ 电话报修   ─┼─→ 工单创建 → 派单 → 工程师接单
           └─ 销售上报   ─┘                       │
                                                  ↓
        关单 ←─ 客户签字 ← 收款 ← 录入更换件 ← 上门拆检
            │                       │
            │                       ↓
            └─ 三包件 ──→ 三包索赔流程
            └─ 非三包 ──→ 配件销售单
```

**步骤**：

1. **报修录入**：渠道收口于工单中心，含故障描述、紧急程度、GPS、期望时间
2. **派单**：调度员视图（地图 + 列表）拖拽派单，或系统按规则自动派单（距离 + 技能 + 负载）
3. **接单**：工程师 App 接单，可改约、转派、拒接（带原因）
4. **上门定位打卡**：到达客户位置打卡，开始计时
5. **拆检诊断**：拍照、录入故障代码、确认故障件
6. **取件 / 出库**：从工程师随身件库 / 最近门店出库（PDA 扫码）
7. **更换 / 维修**：录入工时、更换件清单
8. **客户签字**：电子签名 + 拍照留档
9. **收款**：现金 / 微信 / 支付宝 / 挂账（需有客户授信）
10. **关单**：自动写入客户机器档案、累加工时
11. **后续单据**：
    - 三包件 → 自动生成三包索赔单（待提交）
    - 非三包件 → 自动生成销售出库单 + 应收

**异常处理**：

- 离线工作：无网络区域工程师 App 本地存储，恢复后自动同步
- 二次上门：故障未解决可生成续单，与原工单关联
- 客户拒签：工程师拍照留证 + 客服回访

## 3.7 保养计划与提醒流程

**参与者**：系统、客户、调度员、工程师

**步骤**：

1. **基线设置**：每个机型预设保养周期（如 250h、500h、1000h）+ 对应配件包
2. **机器档案累计**：工单完成时自动累加工作小时数
3. **触发提醒**：当机器累计 ≥ 下次保养小时数 × 90% 时触发
4. **生成保养预订单**：配件清单 + 工时 + 报价
5. **客户确认**：小程序通知客户，确认或推迟
6. **派单上门**：转入服务工单流程
7. **完成后**：写回机器档案，下次保养时间自动延后

**异常处理**：

- 客户多次推迟：累积提醒，超阈值升级到客户回访
- 客户已自行保养：客服可手工录入，重置周期

## 3.8 三包索赔全流程

**参与者**：服务工程师、售后主管、区域售后中心、整机厂、财务

```
 服务工单 ─→ 三包索赔单(草稿)
              │
       服务工程师补充资料
              ↓
        售后主管初审 ─── 驳回 ──→ 补充资料
              │
      ┌──────────────┐
      │  提交区域中心  │
      └───────┬──────┘
              │
       区域中心审核 ──── 驳回 ──→ 补充资料
              │
      ┌──────────────┐
      │   提交整机厂   │
      └───────┬──────┘
              │
       整机厂审核 ──── 驳回 ──→ 关闭 / 补充重提
              │
       通过 + 结算 ──→ 应收 + 故障件返厂 ──→ 闭环
```

**关键控制点**：

- 索赔单必须关联客户机器档案 + 故障件序列号
- 政策匹配：系统自动按机器购买日期 + 机型三包政策判定是否在保
- 资料完整性：故障件照片、铭牌照片、维修工单、客户签字 5 项必填
- 故障件返厂：政策要求时，系统自动生成返厂物流单据
- 结算回款：整机厂结算后自动核销应收

**异常处理**：

- 整机厂驳回：驳回原因留档，工程师补充重提，累计驳回率作为绩效
- 资料丢失：可在小程序补传照片
- 跨季节件：故障件返厂时间长（如发动机），单独跟踪节点

## 3.9 跨区代发流程

**参与者**：客户机手、原服务方、代发方、调度员

**场景**：跨区作业的机器在外地报修

**步骤**：

1. 客户在小程序报修，提交当前 GPS 位置 + 机型 + 故障件
2. 系统按"距离最近 + 库存充足 + 合作信用"匹配代发候选名单
3. 调度员选择代发方，发起请求 → 代发方确认接单
4. 系统自动生成跨区代发单：
    - 代发方：销售出库单（按内部成本价 + 服务费）
    - 原服务方：采购入库单（虚拟）→ 销售出库单（结算到客户）
5. 代发方就近发货 + 派工程师上门
6. 月底系统按代发协议自动结算

## 3.10 库存调拨流程

**参与者**：申请方仓库、审批方、发出方仓库

**步骤**：

1. 申请方发起调拨申请：SKU、数量、目标仓
2. 审批通过后，发出仓库生成出库单 → 物理出库
3. 系统创建"调拨在途"虚拟库存
4. 接收仓库物理收货 → 扫码确认 → 自动核销在途
5. 跨公司调拨：按内部成本价生成应收应付，月底自动结算

**异常处理**：

- 在途丢失 / 损坏：发起调拨差异单，做盘亏 / 索赔流程
- 长期未签收：超时预警 + 强制平账

## 3.11 库存盘点流程

**参与者**：仓库、财务

**步骤**：

1. **创建盘点单**：选择盘点范围（全盘 / 抽盘 / 循环盘点）
2. **冻结库存**：相关 SKU 的可用量临时锁定
3. **PDA 录入**：仓库人员扫码录入实物数量
4. **差异分析**：系统对比账面数 → 生成差异表
5. **复盘**：差异 SKU 重盘
6. **审核**：盘点主管审核
7. **生成调整单**：盘盈生成入库单（其他入库），盘亏生成出库单（盘亏）
8. **解冻库存**：盘点关闭，库存可用

**异常处理**：

- 重大差异（金额 / 比例超阈值）：升级审批
- 盘点期间收发货：先入暂存仓 → 盘点结束后归位

## 3.12 政府补贴销售流程

**参与者**：销售员、客户、财务、政策审核

**步骤**：

1. 销售订单标记为"补贴销售"，选择适用政策
2. 必填字段强制校验：客户身份证、户口、银行卡、机器出厂号、发动机号、申请表
3. 系统自动按政策计算补贴金额、客户自付金额
4. 客户付自付部分 → 出库 → 上传申请材料到政府系统（线下）
5. 在系统中维护申报状态：未申报 → 已申报 → 已通过 → 已到账
6. 补贴款到账后自动核销补贴应收

**关键控制**：

- 资料完整性校验：缺一不能下单
- 同一客户同期补贴次数限制
- 凭证留存：所有材料扫描件归档，便于审计
