# 农机配件管理系统 产品文档

面向农机经销商、农机维修服务站、农机合作社、整机厂区域售后中心的一体化业务管理系统。围绕"按机型卖配件、按农时备库存、按三包做服务"三个核心业务诉求，覆盖采购、库存、销售、三包售后、保养提醒、补贴台账、财务、报表分析的全链路。

## 农机配件行业的特殊性

本产品在通用进销存基础上，针对农机配件行业的强行业属性做了原生支持：

- **机型库**：拖拉机、收割机、插秧机、烘干机、植保机等多品类机型档案，配件按机型适配
- **农时强季节**：春耕、夏收、秋收三个高峰决定库存与排程，系统内置农时日历
- **三包索赔**：对接整机厂三包政策，索赔单据流转闭环
- **保养提醒**：基于客户机器的工作小时 / 作业亩数推送保养与配件预订
- **下沉网络**：县乡村三级网点的配件分仓、跨区作业配件追配
- **农机补贴**：购置补贴、报废更新等政策台账与凭证留存
